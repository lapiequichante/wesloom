# Environment maps

The renderer ships no environment: an application supplies the image.
`lakeside_sunrise_1k.hdr` is the repository's default, loaded by the
gallery, the viewer and the Dawn probe scenes so their pictures match
across machines. The viewer's `H` key cycles it with the other two, an
overcast sky and a sunny one.
